Class challenge, announced ahead

John and Mario: an optional challenge on a class, set ahead so members know it before they come in. The teacher still ticks the winner in the roll call with the same Challenge +3 chip. Nothing changes in how points work.

  • Optional per class. A class with no challenge works exactly like today (the chip still shows in the roll call).
  • Every week or just this one. Set it once on a class and it repeats every week at that time, or set it for one date only. A one-off date wins over the weekly one.
  • Who sets it: owners and instructors (John included), from the class card menu. Camperdown teachers don't have to do anything.
  • Where members see it: on the class card in Classes, and on the gym TV "Up next" screen before the class.
  • Only during a challenge with Challenge points on (the Christmas Cup). Outside it the field is hidden, because the chip gives no points.
